# Third-party code

PotentialBox's own code is MIT licensed (see LICENSE). The release zip contains PotentialBox's own files plus the AKWF
wavetables listed below. The installer downloads these projects from their official sources (python.org and PyPI) onto your PC; they are used
under their own licences.

| Project | Used for | Licence | Source |
|---|---|---|---|
| Python 3.12 (with Tcl/Tk) | Runs the app and draws the screen | PSF License; Tcl/Tk BSD-style | https://www.python.org |
| NumPy | Sound processing | BSD-3-Clause | https://numpy.org |
| SciPy | Filters and WAV reading | BSD-3-Clause | https://scipy.org |

| mido | MIDI messages | MIT | https://github.com/mido/mido |
| python-rtmidi (RtMidi) | MIDI input | MIT | https://github.com/SpotlightKid/python-rtmidi |

## Fonts and theme

The app uses the fonts already on your PC (Bahnschrift on Windows 10/11). The manual is set in Barlow Semi Condensed
(SIL Open Font License 1.1). The colour theme is the shared Potential theme (`potentialbox/potential-theme.conf`).

## Sounds

All drum sounds in the built-in kits are generated by PotentialBox's own code. No third-party drum samples are included.

24 of Synth 2's wavetables (`potentialbox/akwf_tables.npz`) are built from **AKWF-FREE**, the Adventure Kid single-cycle
waveforms by Kristoffer Ekstrand, released under **CC0 1.0** (public domain): https://github.com/KristofferKarlAxelEkstrand/AKWF-FREE.
16 waveforms from each of 24 AKWF folders are stored as spectra, so Synth 2 can morph between them.
